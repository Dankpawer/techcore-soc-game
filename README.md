# TECHCORE // Cyber SOC & IT Analyst Simulator - 4 Turnos

Simulador tático e interativo de Operações de Segurança da Informação (SOC) e TI corporativa.

## 🎮 Sobre o Jogo

O **TechCore Cyber SOC Simulator** coloca o jogador no papel de um Analista de Segurança encarregado de defender a infraestrutura da empresa **TechCore Systems Corp.** contra ciberataques, engenharia social, invasões de banco de dados e campanhas de phishing.

### 🛡️ Módulos e Turnos
- **Turno 1: Fundamentos de TI & Engenharia Social** — Monitoramento de e-mails corporativos (`TechMail`), Pull Requests do GitHub e controle de privilégios IAM.
- **Turno 2: Auditoria de Banco de Dados & Infraestrutura Mista** — Análise de logs SQL do `TechDB`, injeções de SQL (`UNION SELECT`, `DROP TABLE`), phishing com hífen e scripts no CI/CD.
- **Turno 3: Contas Comprometidas & TechZap Chat** — Verificação de crachás corporativos e resposta a impostores no chat do `TechZap` (WhatsApp corporativo).
- **Turno 4: Contrainteligência & Envio de Arquivos** — Despacho seguro de arquivos via `TechVault`, emboscadas digitais com Honeytokens e aplicação de hotfixes de segurança.

---

## 🚀 Como Executar

### Localmente
Basta abrir o arquivo `index.html` em qualquer navegador web moderno (Chrome, Edge, Firefox, Safari).

### No GitHub Pages
Suba o conteúdo desta pasta para a branch `main` ou `gh-pages` do seu repositório no GitHub para publicar o jogo online automaticamente.
